🇬🇧 English Version
Orizon Viewer is a desktop Excel file viewer built with Python and CustomTkinter.
It provides a clean, modern interface for loading, searching, and viewing Excel data, with barcode generation and popup details.

🔹 Features
Import and view .xlsx files
Real-time search and filtering
Barcode generation for each item
Fullscreen view and dark theme
Popup window with item details

⚙️ Requirements

pip install pandas
pip install customtkinter
pip install pillow
pip install python-barcode


🚀 Run the app
python main.py





-------
Install on Windows .exe 

pyinstaller --noconfirm --onefile --windowed --add-data "Orizon-com.jpg;." main.py
